// The Pipeline
01 / SENDER
AI Compression
PCA autoencoder + block DCT shrinks 8MB → ~100KB. zlib finishes the job.
02 / SENDER
AES-256 Encrypt
PBKDF2 key derivation. AES-GCM with authentication tag. Wrong password = fail.
03 / SENDER
LSB Steganography
2 LSBs per audio sample modified. Inaudible change, <0.003% deviation.
04 / RECEIVER
LSB Extract
Reads modified LSBs from audio, reassembles encrypted payload.
05 / RECEIVER
AES Decrypt
Password derives key. GCM tag verifies integrity. Compressed data recovered.
06 / RECEIVER
AI Reconstruct
Inverse PCA + inverse DCT reconstructs image. Bilinear upsampling restores size.
